# AI Code Assistant

AI-powered web application for managing coding projects and providing AI-assisted code support.

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- JavaScript

## Features

- User Authentication
- Project Management
- Dashboard Interface
- MongoDB Integration
- AI-assisted Coding Features

## Run Locally

```bash
npm install
npm start
```
